# LeetCode 389: Find the Difference

## Problem

You are given two strings `s` and `t`.

String `t` is generated by randomly shuffling string `s` and then adding one extra character at a random position.

Return the character that was added to `t`.

## Approach

We can solve this problem using a **Vector and Linear Search** approach.

The idea is to store all characters of string `s` inside a vector and then check whether each character of string `t` exists in that vector.

### Steps

1. Create an empty character vector `answer`.
2. Traverse string `s` and insert every character into the vector using `push_back()`.
3. Traverse string `t` character by character.
4. For each character `w`:
   - Use `find()` to search for `w` inside the vector.
   - If `find()` returns `answer.end()`, it means the character does not exist in the vector. This is the extra character, so return it.
   - Otherwise, erase the found character using `erase(it)`.
5. Continue until the extra character is found.
6. Return a space as a fallback.

### Key Concept: find() and erase()

**1. find()**

The `find()` function searches for a particular element in a range.

```cpp
auto it = find(answer.begin(), answer.end(), w);
```

- `answer.begin()` represents the starting position.
- `answer.end()` represents the position after the last element.
- `w` is the character we want to find.
- If the character is not found, `find()` returns `answer.end()`.

**2. erase()**

The `erase()` function removes an element from the vector using its iterator.

```cpp
answer.erase(it);
```

We remove the matched character because it has already been accounted for.

This is important because characters can repeat. Removing each matched occurrence ensures that the same character in `s` cannot be matched multiple times.

## C++ Solution

```cpp
class Solution {
public:
    char findTheDifference(string s, string t) {
        vector<char> answer;

        for(char c:s){
            answer.push_back(c);
        }

        for(char w:t){
            auto it = find(answer.begin(), answer.end(), w);

            if(it == answer.end()){
                return w;
            }
            else{
                answer.erase(it);
            }
        }

        return ' ';
    }
};
```

## Example

**Input:**

```text
s = "abcd"
t = "abcde"
```

**Output:**

```text
"e"
```

**Explanation:**

First, we insert all characters of `s` into the vector:

```text
answer = ['a', 'b', 'c', 'd']
```

Now we traverse `t`:

| Character | Found in vector? | Operation |
|---|---|---|
| a | Yes | Remove a |
| b | Yes | Remove b |
| c | Yes | Remove c |
| d | Yes | Remove d |
| e | No | Return e |

The character `'e'` is not present in the vector, so it is the extra character.

## Complexity Analysis

Let `n` be the length of string `s`.

**Time Complexity: O(n²)**

- Inserting all characters into the vector takes O(n).
- `find()` takes O(n) in the worst case.
- `erase(it)` takes O(n) in the worst case because subsequent elements may need to be shifted.
- We perform these operations for each character in `t`.

Therefore, the overall time complexity is **O(n²)**.

**Space Complexity: O(n)**

- We create a separate vector containing all characters of `s`.
- The vector stores `n` characters.

Therefore, the auxiliary space complexity is **O(n)**.

## Key Takeaway

This problem demonstrates how to use:

- `vector<char>` to store characters.
- `push_back()` to insert elements.
- `find()` to search for an element.
- `erase()` to remove an element using an iterator.
- `auto` to automatically determine an iterator's type.

**Important observation:** Removing matched characters handles duplicate occurrences correctly because each character in `t` must match a separate occurrence in `s`.

The solution is straightforward, but its O(n²) time complexity leaves room for optimization using techniques such as character frequency counting or XOR.
